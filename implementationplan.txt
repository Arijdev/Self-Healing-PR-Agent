**Context & Role:**
You are a Staff AI Engineer and Senior Python Architect. Build an **Autonomous Self-Healing Repo-Maintenance & PR Agent** using **LangGraph, Python 3.10+, and the Google Gemini API (`langchain-google-genai`)**. The system must run either locally via CLI/Streamlit or triggered headlessly via GitHub Actions.

---

### Project Architecture & Requirements

**1. Tech Stack:**

* **Orchestration:** LangGraph (StateGraph with cycles and conditional edges).
* **LLM Engine:** Gemini 1.5 Flash / Pro (or Groq Llama 3) via LangChain.
* **Testing & System Operations:** Python `subprocess` (executing `pytest`), `os`, `pathlib`.
* **Git Operations:** `GitPython` / GitHub REST API (for automated branching, commits, and PR generation).
* **UI Layer:** Optional minimal Streamlit UI visualizing state transitions.

**2. State Schema (`AgentState`):**

* `task_description`: string (e.g., "Refactor math utilities and add 100% test coverage").
* `target_files`: list of file paths.
* `generated_code`: dict mapping file paths to new/modified code strings.
* `test_files`: dict mapping test file paths to test code.
* `test_output`: string (captured `stdout` and `stderr` from `pytest`).
* `test_status`: boolean (`True` if exit code 0, else `False`).
* `iteration_count`: integer (to prevent infinite loops, max = 3).
* `human_approved`: boolean (HITL gate flag).
* `pr_url`: string.

**3. State Graph Nodes & Flow:**

* **Node 1: `planner_and_coder**`
* Reads target files and writes/refactors implementation code.


* **Node 2: `test_generator**`
* Reads the modified code, drafts comprehensive unit tests using `pytest`, and writes them to disk.


* **Node 3: `test_executor**`
* Runs `pytest` via a secure `subprocess.run()` sandbox.
* Captures exit code and `stderr` tracebacks into `test_output`.


* **Conditional Edge: Self-Healing Loop**
* If `test_status == False` and `iteration_count < 3`: route to `healer_node` (feeds error traceback back to Gemini to rewrite faulty code), increment `iteration_count`, then re-route to `test_executor`.
* If `test_status == True` or `iteration_count >= 3`: route to `hitl_gate`.


* **Node 4: `hitl_gate` (Human-in-the-Loop)**
* Pauses execution using LangGraph's native breakpoint or interactive prompt, requesting human verification before touching Git.


* **Node 5: `git_pr_creator**`
* Creates a new branch (e.g., `fix/agent-refactor-<timestamp>`), commits all verified changes, pushes to remote GitHub, and opens a Pull Request with an auto-generated changelog summary.
